# Meet the author: 3D version

`out/meet-the-author-3d-vertical-1080x1920.mp4`: 1080×1920, 30 fps, 46.5 s. Same script and timing as `author1/`, rebuilt in the 3D tabletop world.

| Time | Scene |
|---|---|
| 0–7 | The SOMEDAY drawer clicks open. Three cards rise and hover: "Dreams / Ideas / Plans" |
| 7–11 | Brass PREPARING and DOING plates. The gold line climbs from one towards the other and knots itself short of DOING |
| 11–15.5 | The author's portrait as a framed print on the table, with a brass name plate and the "Meet the author" lower third |
| 15.5–23 | The 3D book rises and opens. "Why we overthink / chase new ideas / struggle to follow through" lift off the pages |
| 23–29.5 | The SELECT method ticket and the 30-day calendar rise out of the book |
| 29.5–34.5 | The quote over the writing image (Canva-generated) |
| 34.5–46.5 | End card over the blurred 3D book |

To build `video.html` from `src/`, run `tools/assemble.sh`. To render, run `node render.js` (about 40 minutes); `--stills 3,9` writes PNG frames only.
